# Soul Pressure | 魂壓 (Fabric 1.20.1)

## Updated behavior
- Area soul pressure radius: 30 blocks
- Single-target lock range: 50 blocks
- Area field remains fixed at the cast position until toggled off
- Soul-pressured entities are immobilized, cannot rotate, and remain pinned even in mid-air
- Left-clicking a soul-pressured entity instantly kills it
- Visuals emphasize a dark-gray gravity-crush style with stronger downward shafts
- Frozen targets are rendered in translucent gray on the client

## Controls
- `R`: Toggle area soul pressure
- `V`: Toggle single-target soul pressure

## Build
Use the included GitHub Actions workflow or run `gradle build`.
